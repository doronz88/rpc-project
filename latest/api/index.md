# API Reference

Generated from the `rpcclient` source. The client is organized as a per-platform `Client` built on a shared core, exposing subsystems as attributes (`p.fs`, `p.network`, `p.processes`, …).

- **[Core client](https://doronz88.github.io/rpc-project/latest/api/core/index.md)** — the abstract client, symbols, and exceptions.
- **[Platform clients](https://doronz88.github.io/rpc-project/latest/api/clients/index.md)** — Linux / macOS / Darwin / iOS clients.
- **[Darwin subsystems](https://doronz88.github.io/rpc-project/latest/api/darwin/index.md)** — filesystem, network, processes, HID, media, and more.
- **[iOS subsystems](https://doronz88.github.io/rpc-project/latest/api/ios/index.md)** — MobileGestalt, SpringBoard, lockdown, backlight, and more.

New here? Start with the [Quick start](https://doronz88.github.io/rpc-project/latest/guides/quickstart/index.md) and [Calling native functions](https://doronz88.github.io/rpc-project/latest/guides/calling-native-functions/index.md) guides.
